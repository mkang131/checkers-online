# Online Checkers Desktop

Desktop-приложение для игры в шашки вдвоем по сети. Один игрок запускает сервер прямо из приложения, второй подключается по LAN-адресу и коду комнаты.

## Запуск

Самый простой способ на Windows:

1. Запустить `dist\Checkers Online.exe`.
2. Или один раз нажать `create-exe-shortcut.bat`, чтобы создать ярлык на рабочем столе.
3. После этого запускать игру через ярлык `Checkers Online`.

Режим разработки:

Можно запускать напрямую через `Запустить шашки.bat` или `launch-checkers.bat`, но тогда будет открываться командная строка.

Через терминал:

```powershell
npm install
npm start
```

Собрать новый `.exe`:

```powershell
npm run build
```

## Как играть онлайн

1. Первый игрок нажимает `Хостить`, затем `Создать`.
2. Он отправляет другу адрес из блока `Адрес для друга` и код комнаты.
3. Второй игрок вводит адрес в поле `Сервер`, код в поле `Код комнаты` и нажимает `Подключиться`.

Если вы не в одной локальной сети, серверный порт `8787` должен быть доступен второму игроку через VPN, проброс порта или отдельный публичный сервер.

## Правила в текущей версии

- Красные ходят первыми.
- Взятие обязательно.
- Обычная шашка ходит вперед, но бьет вперед и назад.
- Дамка ходит и бьет по диагонали на любое расстояние.
- Если после взятия доступно следующее взятие, ход продолжается той же шашкой.
